# 🧭 Astanik AI — Умный ИИ-гид по прогулкам в Астане (RAG + Multimodal Vision + Audio Guide)

Полнофункциональное веб-приложение (Mobile-First PWA) для хакатона **НИЦ Smart City**: интеллектуальный помощник по пешим маршрутам, архитектуре, кофейням и событиям города Астана.

---

## ✨ Ключевые возможности продукта

1. **🧭 Персонализированный подбор мест и маршрутов (Главная)**
   - 5 готовых сценариев хакатона в 1 клик (*прогулка у Mega Silk Way*, *тихое место с кофе и розеткой*, *с ребёнком и интерактивами*, *турист: 2 часа до вылета*, *ночной вайб*).
   - Геймификация в стиле **Admitly AI**: система опыта (`XP`), уровней исследователя Астаны, стриков и интерактивный 3D-маскот Астаник.
   - Вертикальные **Видео-сторис (Reels)** с авто-озвучкой и живые отзывы жителей.

2. **🗺️ Живая Карта с последовательным маршрутом (`Я -> 1 -> 2 -> 3`)**
   - Построение оптимального пешего маршрута по алгоритму *Nearest-Neighbor* от текущей точки пользователя без «зигзагов».
   - Круглые фото-пины с номерами остановок, расчёт точной дистанции (формула Гаверсинуса) и времени пешком (`5 км/ч`).

3. **📷 Живая Камера с голосовой историей зданий (WebRTC + Vision + TTS)**
   - Поддержка реальной камеры смартфона/ноутбука (`navigator.mediaDevices.getUserMedia`), загрузки собственного фото объекта и 4 панорамных пресетов достопримечательностей Астаны.
   - Автоматическая голосовая озвучка истории здания (*Web Speech API*) со встроенным аудио-плеером, эквалайзером и подсказкой, куда повернуть за ближайшим кофе с розетками.

4. **🎧 Аудио-прогулки по Астане**
   - 3 полноценных аудио-маршрута с таймкодами глав (`00:00`, `12:00`, `22:00`), переключением скорости речи (`1.0x` / `1.25x`) и переносом маршрута на карту.

5. **👥 Совместные прогулки (Group Consensus) и Живая Афиша на сегодня**
   - Интерактивный калькулятор группового мэтча (*Group Consensus Match %*) по интересам компании друзей.
   - Живая афиша сегодняшних событий, концертов и световых шоу Астаны с добавлением в прогулку в 1 клик.

6. **⚙️ Инженерная панель «О системе» (для жюри хакатона)**
   - Многоступенчатый **Spatial RAG Pipeline**:
     $$\text{HybridScore} = 0.40 \cdot \text{Proximity} + 0.40 \cdot \text{TagMatch} + 0.20 \cdot \text{Rating}$$
   - **Privacy-by-Design (`±150м`)**: размытие точных GPS-координат перед отправкой запроса.
   - Живая синхронизация базы POI с **OpenStreetMap Overpass API** и реальных фотографий с **Wikipedia PageImages API / Wikimedia Commons**.
   - Встроенный **авто-тестер всех 5 сценариев хакатона** с проверкой задержки (`Latency`), `Confidence` и `JSON`-спецификации.

## 🚀 Быстрый запуск локально

### 1. Клонирование и установка зависимостей
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd astanik-ai
npm install
```

### 2. Настройка переменных окружения (опционально)
Скопируйте `.env.example` в `.env` и при необходимости укажите ключ `GEMINI_API_KEY` (приложение также полностью работает автономно на детерминированном движке Smart RAG без внешних ключей):
```bash
cp .env.example .env
```

### 3. Запуск Full-Stack сервера (Express + Vite на порту 3000)
```bash
npm run dev
```
Откройте в браузере: `http://localhost:3000`

### 4. Запуск модульных тестов RAG-математики и сборка продакшен-билда
```bash
node --test src/utils/ragMath.test.ts
npm run build
```

## 🛠️ Технологический стек
- **Frontend**: React 19, TypeScript, Tailwind CSS 4, Motion (Framer Motion), Lucide Icons, Leaflet
- **Backend / API**: Node.js, Express (`server.ts`), `@google/genai` (Gemini 2.5 Flash для RAG-синтеза и мультимодального распознавания архитектуры)
- **Открытые данные Астаны**: OpenStreetMap Overpass API, Wikipedia PageImages API, Wikimedia Commons, Web Speech API (`speechSynthesis`)
